Recurrent networks: from kernel to pattern

How local excitation and wider inhibition single out one spatial frequency, and how a ring of neurons wired that way turns random input into stripes.

Many parts of cortex are wired in a similar way: neurons excite their close neighbours and, through interneurons, inhibit cells a bit further away. This “Mexican hat” arrangement is simple to write down, but what it does to activity is not obvious at first sight. The short version is that such a network has a favourite spatial scale. It amplifies activity patterns at one particular wavelength and damps everything else, so almost any input comes out striped. This is one of the standard explanations for periodic patterns in cortex, such as orientation columns or the regular spacing of ocular dominance bands (Swindale 1980; Ermentrout and Cowan 1979), and it is the neural cousin of Turing’s (1952) mechanism for patterns in chemistry and development.

This page is in two parts. The first looks at the connection kernel alone and asks which spatial frequency it favours. The second puts the kernel into a network and lets you watch the stripes emerge. Everything runs in your browser and updates while you move the sliders.

Difference of Gaussians and its spectrum

Write the strength of the connection between two neurons as a function of their distance. Excitation is a narrow Gaussian with width \(\sigma_e\), inhibition a wider one with width \(\sigma_i\), and the kernel is the difference of the two. Up close excitation wins and the kernel is positive; further out the broader inhibition takes over and it becomes negative.

The useful trick is to look at this kernel in the Fourier domain. A recurrent network applies the kernel to its activity over and over again, and convolution with a kernel multiplies each spatial frequency of the activity by the kernel’s Fourier transform at that frequency. So the transform tells you directly which frequencies get amplified on every pass and which get suppressed. The Fourier transform of a Gaussian is again a Gaussian, with a width inversely proportional to the original one. The narrow excitatory Gaussian therefore covers a wide band of frequencies, the broad inhibitory Gaussian only the low ones. Their difference is small at frequency zero, where inhibition cancels excitation, rises to a peak, and then falls off again once excitation runs out. That peak is the frequency the network will favour.

gauss = (x, s) => Math.exp(-0.5 * x * x / (s * s)) / (Math.sqrt(2 * Math.PI) * s)
ghat = (f, s) => Math.exp(-2 * Math.PI * Math.PI * s * s * f * f)
xmax = 5 * Math.max(sigE, sigI)
space = Array.from({length: 401}, (_, i) => {
  const x = -xmax + 2 * xmax * i / 400;
  const e = ampE * gauss(x, sigE), inh = -ampI * gauss(x, sigI);
  return {x, Excitation: e, Inhibition: inh, "Difference of Gaussians": e + inh};
})
spectrum = Array.from({length: 401}, (_, i) => { const f = 2 * i / 400; return {f, k: Math.abs(ampE * ghat(f, sigE) - ampI * ghat(f, sigI))}; })
peak = spectrum.reduce((a, b) => (b.k > a.k ? b : a))

The left plot shows the excitatory Gaussian in orange, the inhibitory one in blue, drawn negative, and their difference in black. The right plot is the magnitude of the kernel’s Fourier transform, with the orange dashed line at its peak. With the default settings the peak sits at about 0.15 cycles per unit length, a wavelength of six to seven units, a few times the width of the inhibitory surround.

A few things are worth trying before moving on. Make inhibition wider and the peak moves to lower frequencies: the stripes the network will produce get broader. Make excitation wider, closer to the inhibition width, and the peak gets lower and broader, since the two Gaussians cancel over a larger range of frequencies. Set the inhibition strength to zero and the peak moves to frequency zero, meaning the network would simply amplify uniform activity rather than any pattern. The Mexican hat shape, not just excitation, is what makes stripes.

Pattern formation in a recurrent network

Now wrap 256 neurons around a ring, so that there are no edges to worry about, and connect each pair with a weight given by the kernel above. The firing rates \(r\) evolve according to

\[\tau \frac{dr}{dt} = -r + \left[\,W r + h\,\right]_+ .\]

Each neuron relaxes towards its total input with time constant \(\tau\). The input has two parts: the recurrent input \(W r\) from the rest of the ring, and an external input \(h\) that is drawn at random once per neuron and then held fixed. On top of that you can add noise that is redrawn at every time step. The brackets denote rectification, so rates cannot go negative. The width sliders set the two Gaussians of the kernel, in units of neurons along the ring.

The gain slider is the one to watch. It scales the whole weight matrix so that its largest eigenvalue equals the number you set. Because the kernel depends only on distance, the eigenvectors of \(W\) are sine waves around the ring, one for each spatial frequency, and the eigenvalues are the kernel’s Fourier transform from the first part of the page. If the largest eigenvalue is below 1, every pattern decays faster than the recurrence can feed it, and the activity just reflects the random input. If it is above 1, the pattern at the favoured frequency grows on each pass through the network until the rectification stops it. That is the transition from a stable, input-driven network to one that generates its own pattern.

Code 
rnN = 256
rnKernel = {
  const N = rnN, sE = rnSigE, sI = rnSigI;
  const g = (d, s) => Math.exp(-0.5 * d * d / (s * s)) / s;
  const k = new Float64Array(N);
  for (let d = 0; d < N; d++) { const dd = Math.min(d, N - d); k[d] = g(dd, sE) - g(dd, sI); }
  const ev = new Float64Array(N / 2 + 1);
  for (let m = 0; m <= N / 2; m++) { let s = 0; for (let d = 0; d < N; d++) s += k[d] * Math.cos(2 * Math.PI * m * d / N); ev[m] = s; }
  let lmax = -Infinity, mmax = 0; for (let m = 0; m <= N / 2; m++) if (ev[m] > lmax) { lmax = ev[m]; mmax = m; }
  const scale = rnGain / lmax;
  return {N, k: k.map(x => x * scale), ev: ev.map(x => x * scale), mmax};
}
rnState = {
  rnReset;
  const N = rnN, dt = 0.1, tau = 1;
  const h = Float64Array.from({length: N}, () => 0.5 + 0.5 * Math.random());
  let r = new Float64Array(N).fill(0.5), t = 0;
  while (true) {
    if (!viewof rnPause.value) {
      const {k} = rnKernel; const noise = viewof rnNoise.value;
      for (let step = 0; step < 5; step++) {
        const rn = new Float64Array(N);
        for (let i = 0; i < N; i++) {
          let s = 0;
          for (let j = 0; j < N; j++) { const d = (i - j + N) % N; s += k[d] * r[j]; }
          rn[i] = r[i] + dt / tau * (-r[i] + Math.max(0, s + h[i] + noise * (Math.random() - 0.5) * 2));
        }
        r = rn; t += dt;
      }
    }
    yield {r, t};
  }
}

Reading the figure

The upper panel shows the activity of every neuron as a bar, laid out by position on the ring, with the clock in units of \(\tau\) underneath. The lower panel shows the eigenvalues of \(W\), one grey dot for each spatial frequency, counted in whole waves around the ring. This is the same curve as the kernel spectrum in the first part of the page, just sampled at the frequencies that fit on the ring and scaled by the gain. The orange dot is the largest eigenvalue, and the red dashed line marks the value 1, the boundary between decay and growth.

With the default settings the gain is 1.2 and the orange dot sits above the line. After a moment the activity organises into a regular set of bumps, and if you count them you will find the number next to the orange dot. The random input is still there, which is why the bumps are not all the same height, but the spacing is set entirely by the kernel.

Things to try

Pull the gain below 1 and press Reset. The bumps fade and what is left is a noisy copy of the random input: the network is now a filter that smooths its input a little, nothing more. Push the gain back above 1 and the pattern grows back, from whatever small ripples in the input happen to match the favoured frequency. Near the threshold the growth is slow and you can watch it happen.

Make the inhibition wider. The orange dot moves left, to a lower frequency, and after a Reset the bumps are fewer and broader. Make excitation wider instead and the bumps get broader too, but the peak of the spectrum also gets flatter, so neighbouring frequencies compete and the pattern takes longer to settle.

Turn the noise up. The pattern survives surprisingly well, because the network amplifies only the component of the noise at its favourite frequency and ignores the rest. This is the sense in which a recurrent network with a Mexican hat kernel imposes its own structure on whatever it is given, and why the same mechanism has been proposed for so many different periodic patterns in the brain.

This page is based on the pattern-formation exercise in Dayan and Abbott (2001, chapter 7). The ring network with a distance-dependent kernel is the setting of Amari’s (1977) analysis of neural fields, and the same architecture, with the ring standing for preferred orientation rather than position, is the ring model of orientation tuning of Ben-Yishai et al. (1995).
