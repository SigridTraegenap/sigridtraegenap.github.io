The leaky integrate-and-fire neuron

The simplest model of a spiking neuron: a live membrane trace, a dose of noise, and an f-I curve that fills in as you explore.

A real neuron is a complicated thing, but a surprising amount of its behaviour can be captured by treating it as a leaky bucket. Current flows in, the membrane voltage rises, some of it leaks away, and once the voltage reaches a threshold the neuron fires a spike and starts over. That is the leaky integrate-and-fire model. It goes back to Lapicque (1907), long before anyone knew what an action potential was made of, and it is still the first model most people meet in computational neuroscience. I used it in a webinar for the German Neuroscience Olympiad in 2020, and this page is the interactive version of that notebook.

Everything runs in your browser. The simulation keeps going while you move the sliders, so you can watch the neuron react to a change in its input.

The model

The only variable is the membrane potential \(V\), measured in millivolts. Left alone, it sits at the resting potential \(V_{\text{rest}} = -65\) mV. An input current \(I\) pushes it away from rest, and the leak pulls it back, so that

\[\tau_m \frac{dV}{dt} = (V_{\text{rest}} - V) + R\,I(t).\]

The membrane time constant \(\tau_m\) sets how fast \(V\) follows a change in input. A small \(\tau_m\) means a nervous neuron that tracks its input closely, a large one means a sluggish neuron that averages over a longer stretch of time. The input resistance \(R\) converts current to voltage and is fixed at 2 MΩ here, so a steady current of 10 nA lifts the voltage by 20 mV in the long run.

The equation alone would just let \(V\) settle at a new level. The spike is added by hand: whenever \(V\) reaches the threshold \(V_{\text{th}}\), the neuron is said to fire, \(V\) is reset to \(V_{\text{reset}} = -70\) mV, and it is held there for a refractory period of 2 ms before the integration starts again. Nothing about the shape of a real action potential is in the model. The spike is just an event, drawn here as a vertical stroke so that you can see it.

With noise switched on, a random Gaussian value is added to the current at every time step. The slider sets the size of these fluctuations. This is a crude stand-in for the thousands of synaptic inputs a cortical neuron receives, which never add up to a perfectly steady current.

Code 
viewof lifI = Inputs.range([0, 25], {value: 8, step: 0.5, label: "Input current (nA)"})
viewof lifNoise = Inputs.range([0, 10], {value: 0, step: 0.5, label: "Input noise (0 = off)"})
viewof lifTau = Inputs.range([2, 50], {value: 10, step: 1, label: "Membrane time constant τ (ms)"})
viewof lifThr = Inputs.range([-60, -35], {value: -50, step: 1, label: "Threshold (mV)"})
viewof lifPause = Inputs.toggle({label: "Pause"})
viewof lifReset = Inputs.button("Reset (also clears the f-I points)")
Code 
lifState = {
  lifReset;
  const dt = 0.1, win = 300, R = 2, Vrest = -65, Vreset = -70, refr = 2;
  const n = Math.round(win / dt);
  const V = new Float32Array(n).fill(Vrest), Iarr = new Float32Array(n);
  let v = Vrest, refrLeft = 0, t = 0;
  const fi = new Map();
  let key = null, sinceChange = 0, spikesSince = 0, lastSig = 0;
  const gauss = () => { let u = 0; while (u === 0) u = Math.random();
                        return Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * Math.random()); };
  while (true) {
    const I0 = viewof lifI.value, sig = viewof lifNoise.value,
          tau = viewof lifTau.value, thr = viewof lifThr.value;
    if (!viewof lifPause.value) {
      const k = `${I0}|${sig > 0}`;
      if (sig > 0 && sig !== lastSig) { for (const [kk, p] of fi) if (p.noisy) fi.delete(kk); }
      if (sig > 0) lastSig = sig;
      if (k !== key) { key = k; sinceChange = 0; spikesSince = 0; }
      for (let s = 0; s < 20; s++) {
        const I = I0 + sig * gauss() / Math.sqrt(dt);
        if (refrLeft > 0) { refrLeft -= dt; v = Vreset; }
        else {
          v += dt / tau * ((Vrest - v) + R * I);
          if (v >= thr) { v = 20; spikesSince++; refrLeft = refr; }
        }
        V.copyWithin(0, 1); V[n - 1] = v;
        Iarr.copyWithin(0, 1); Iarr[n - 1] = I;
        if (v === 20) v = Vreset;
        t += dt; sinceChange += dt;
      }
      if (sinceChange >= 500) fi.set(key, {I: I0, noisy: sig > 0, rate: 1000 * spikesSince / sinceChange});
    }
    yield {V, Iarr, t, win, fi, thr, tau, sig, I0, R, Vrest, refr,
           rate: sinceChange > 0 ? 1000 * spikesSince / sinceChange : 0};
  }
}

  c.strokeStyle = "#888"; c.lineWidth = 1; c.beginPath();

  c.stroke();
  c.strokeStyle = sig > 0 ? orange : blue; c.lineWidth = 1.5; c.beginPath();
  for (let i = 0; i < n; i++) i ? c.lineTo(sx(i), sy(bot, V[i])) : c.moveTo(sx(0), sy(bot, V[0]));
  c.stroke();
  // f-I curve, right
  const fP = {x0: 560, y0: 12, w: 180, h: 300};
  const Imax = 25, fmax = Math.max(100, ...Array.from(fi.values()).map(p => p.rate)) * 1.1;
  const fx = I => fP.x0 + fP.w * I / Imax, fy = f => fP.y0 + fP.h * (1 - f / fmax);
  axisBox(c, fP.x0, fP.y0, fP.w, fP.h);
  c.fillStyle = fg; c.textAlign = "center";
  c.fillText("input (nA)", fP.x0 + fP.w / 2, H - 14);
  c.fillText("0", fx(0), fP.y0 + fP.h + 20); c.fillText(Imax, fx(Imax), fP.y0 + fP.h + 20);
  c.save(); c.translate(fP.x0 - 44, fP.y0 + fP.h / 2); c.rotate(-Math.PI / 2); c.fillText("spikes / s", 0, 0); c.restore();
  c.textAlign = "right"; c.fillText("0", fP.x0 - 6, fy(0) + 5); c.fillText(fmax.toFixed(0), fP.x0 - 6, fy(fmax) + 5);
  c.setLineDash([3, 3]); c.strokeStyle = blue; c.lineWidth = 1; c.beginPath(); let started = false;
  for (let I = 0; I <= Imax; I += 0.1) {
    const d = R * I - (thr - Vrest); if (d <= 0) continue;
    const f = Math.min(fmax, 1000 / (refr + tau * Math.log(R * I / d)));
    started ? c.lineTo(fx(I), fy(f)) : c.moveTo(fx(I), fy(f)); started = true;
  }
  c.stroke(); c.setLineDash([]);
  for (const [k, p] of fi) { c.fillStyle = p.noisy ? orange : blue; c.beginPath(); c.arc(fx(p.I), fy(p.rate), 5, 0, 2 * Math.PI); c.fill(); }
  c.strokeStyle = sig > 0 ? orange : blue; c.lineWidth = 2; c.beginPath(); c.arc(fx(I0), fy(Math.min(rate, fmax)), 8, 0, 2 * Math.PI); c.stroke();
  c.textAlign = "left"; c.fillStyle = blue; c.fillText("noise-free", fP.x0 + 8, fP.y0 + 22);
  c.fillStyle = orange; c.fillText(sig > 0 ? `noise ${sig}` : "noise (off)", fP.x0 + 8, fP.y0 + 44);
  return c.canvas;
}

Reading the figure

The two panels on the left show the last 300 ms of the simulation. The upper one is the input current, the lower one the membrane potential, blue while the input is noise-free and orange once you add noise. The red dashed line is the threshold. Each time the trace touches it you see a spike drawn up to +20 mV, then the voltage drops to the reset value and climbs again. The number in the corner is the firing rate, averaged since you last changed a setting.

The panel on the right is the f-I curve, the firing rate as a function of the input current. This is the standard way to characterise a neuron, and the page builds it up from your own experiments: every input strength you leave the neuron at for half a second adds a dot. Blue dots are noise-free measurements, orange dots were taken at the current noise level. Changing the noise level clears the orange dots, because they no longer belong to the same curve. The open ring shows where the current setting sits.

The blue dashed line is not a measurement. It is the exact firing rate of the noise-free model, which you can work out by hand: the time the voltage needs to climb from reset to threshold under a constant current, plus the refractory period, is one interspike interval, and the rate is its inverse,

\[f = \frac{1}{t_{\text{ref}} + \tau_m \ln \dfrac{RI}{RI - (V_{\text{th}} - V_{\text{rest}})}} .\]

The formula makes two things obvious. Below the rheobase current \(I = (V_{\text{th}} - V_{\text{rest}})/R\), the voltage never reaches threshold and the rate is zero, so the curve has a hard corner. And at large currents the rate saturates at \(1/t_{\text{ref}}\), because the neuron cannot fire faster than once per refractory period.

Things to try

Start with the noise off and raise the current slowly. Nothing happens until you cross 7.5 nA, and then the neuron starts firing at a rate that goes up quickly at first and then more slowly. Your dots should land on the dashed curve.

Now set the current to 6 nA, just below the rheobase, and turn on the noise. The voltage hovers below threshold and crosses it now and then, so the neuron fires at a low and irregular rate where the noise-free model is silent. Take a few measurements at different currents and compare the orange dots with the dashed line. Noise does not just add scatter, it rounds off the corner of the f-I curve, and this smoothing is the main reason real neurons do not show a hard threshold in their rate.

Change the time constant. With a long \(\tau_m\) the voltage trace is smooth and the neuron is slow to respond, but the noise-free f-I curve shifts too, since a slower climb means a longer interval. With a short \(\tau_m\) and noise on, the trace becomes jagged and the firing increasingly random.

The model and the f-I formula are treated in Dayan and Abbott (2001, chapter 5) and at greater length in Gerstner et al. (2014), which also covers what noise does to the firing statistics. Brunel and van Rossum (2007) tell the story of Lapicque’s original paper.
