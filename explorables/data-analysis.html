Data analysis: PCA and Fourier

Principal component analysis on the iris data, and sampling, aliasing and reconstruction with the discrete Fourier transform.

Two workhorses of data analysis, from the exercises in Theoretical Neuroscience. Everything on this page runs in your browser; nothing to install. Change a slider while a simulation is running and it reacts immediately.

Principal component analysis

Fisher’s iris data: 150 flowers, four measurements each. PCA finds the directions of largest variance, the eigenvectors of the covariance matrix.

\[C = \frac{1}{n} X^{\mathsf T} X, \qquad C\, e_k = \lambda_k e_k\]

  • \(X\): the data matrix, 150 rows (flowers) and 4 columns (sepal length, sepal width, petal length, petal width, in cm), with the column means removed. With standardisation on, each column is also divided by its standard deviation.
  • \(C\): the \(4 \times 4\) covariance matrix.
  • \(e_k\): the \(k\)-th principal component, a direction in the four-dimensional measurement space; \(\lambda_k\) its eigenvalue, the variance of the data along it.
  • Explained variance: \(\lambda_k / \sum_j \lambda_j\).

symEig = A => {           // Jacobi eigenvalue iteration for a small symmetric matrix
  const n = A.length, a = A.map(r => r.slice()), v = Array.from({length: n}, (_, i) => Array.from({length: n}, (_, j) => +(i === j)));
  for (let sweep = 0; sweep < 60; sweep++) {
    let off = 0; for (let i = 0; i < n; i++) for (let j = i + 1; j < n; j++) off += a[i][j] ** 2;
    if (off < 1e-18) break;
    for (let p = 0; p < n; p++) for (let q = p + 1; q < n; q++) {
      if (Math.abs(a[p][q]) < 1e-15) continue;
      const th = (a[q][q] - a[p][p]) / (2 * a[p][q]), t = Math.sign(th || 1) / (Math.abs(th) + Math.sqrt(th * th + 1));
      const cs = 1 / Math.sqrt(t * t + 1), sn = t * cs;
      for (let k = 0; k < n; k++) { const akp = a[k][p], akq = a[k][q]; a[k][p] = cs * akp - sn * akq; a[k][q] = sn * akp + cs * akq; }
      for (let k = 0; k < n; k++) { const apk = a[p][k], aqk = a[q][k]; a[p][k] = cs * apk - sn * aqk; a[q][k] = sn * apk + cs * aqk; }
      for (let k = 0; k < n; k++) { const vkp = v[k][p], vkq = v[k][q]; v[k][p] = cs * vkp - sn * vkq; v[k][q] = sn * vkp + cs * vkq; }
    }
  }
  const order = [...Array(n).keys()].sort((i, j) => a[j][j] - a[i][i]);
  return {values: order.map(i => a[i][i]), vectors: order.map(i => { const col = v.map(r => r[i]); const big = col.reduce((b, x) => Math.abs(x) > Math.abs(b) ? x : b, 0); return big < 0 ? col.map(x => -x) : col; })};
}
pca = {
  const rows = irisRaw.rows, d = 4, n = rows.length;
  const mean = Array.from({length: d}, (_, j) => rows.reduce((s, r) => s + r[j], 0) / n);
  const sd = Array.from({length: d}, (_, j) => Math.sqrt(rows.reduce((s, r) => s + (r[j] - mean[j]) ** 2, 0) / n));
  const X = rows.map(r => Array.from({length: d}, (_, j) => (r[j] - mean[j]) / (pcStd ? sd[j] : 1)));
  const C = Array.from({length: d}, (_, i) => Array.from({length: d}, (_, j) => X.reduce((s, x) => s + x[i] * x[j], 0) / n));
  const {values, vectors} = symEig(C);
  const scores = X.map(x => vectors.map(e => e.reduce((s, ei, j) => s + ei * x[j], 0)));
  const total = values.reduce((s, l) => s + l, 0);
  return {X, C, values, vectors, scores, total, species: rows.map(r => r[4]), mean, sd};
}

What you see. Left: each flower as a dot in the chosen coordinates. With species colouring on, blue is setosa, orange versicolor, green virginica; off, every dot is grey, which is what PCA itself sees, since it never uses the labels. When both axes are raw measurements, the first two principal components are drawn as lines through the origin, PC 1 in red and PC 2 in purple, each scaled to two standard deviations of the data along it. Right, top: the share of the total variance carried by each component, as blue bars. Right, bottom: the loadings, how much of each measurement goes into each component.

Try: switch standardisation off and PC 1 is dominated by petal length, simply because it has the largest spread in centimetres. Look at the raw-variable planes to see where PC 1 points. From the dimensionality-reduction exercise in Theoretical Neuroscience.

Sampling and the discrete Fourier transform

A signal made of two sine waves is sampled at \(N\) points spaced \(\Delta x\) apart over an interval of length \(T\). The discrete Fourier transform (DFT) decomposes the samples into frequencies \(f_m = m / T\):

\[y(x) = a_1 \sin(2\pi f_1 x) + a_2 \sin(2\pi f_2 x), \qquad Y_m = \sum_{n=0}^{N-1} y_n\, e^{-2\pi i\, m n / N}\]

  • \(f_1, f_2\): frequencies of the two components in cycles per unit length; \(a_1, a_2\) their amplitudes.
  • \(\Delta x\): sampling interval. \(T\): interval length, so \(N = T / \Delta x\).
  • \(|Y_m| \cdot 2/N\): the amplitude the DFT assigns to frequency \(f_m = m/T\).
  • Nyquist frequency \(f_{\text{Ny}} = 1 / (2 \Delta x)\): the highest frequency the samples can represent. Anything above it is aliased to a lower frequency.
  • \(K\): how many of the strongest DFT components are used to rebuild the signal.
Code 
viewof ftF1 = Inputs.range([0, 12], {value: 1, step: 0.1, label: "f₁ (cycles / unit)"})
viewof ftA1 = Inputs.range([0, 2], {value: 1, step: 0.1, label: "a₁"})
viewof ftF2 = Inputs.range([0, 12], {value: 3.5, step: 0.1, label: "f₂ (cycles / unit)"})
viewof ftA2 = Inputs.range([0, 2], {value: 0.5, step: 0.1, label: "a₂"})
viewof ftDx = Inputs.range([0.02, 0.5], {value: 0.1, step: 0.01, label: "Sampling interval Δx"})
viewof ftT = Inputs.range([1, 8], {value: 4, step: 0.5, label: "Interval length T"})
viewof ftK = Inputs.range([0, 10], {value: 2, step: 1, label: "K components kept for reconstruction"})
Code 
ft = {
  const T = ftT, dx = ftDx, N = Math.max(4, Math.floor(T / dx)), x0 = -T / 2;
  const sig = x => ftA1 * Math.sin(2 * Math.PI * ftF1 * x) + ftA2 * Math.sin(2 * Math.PI * ftF2 * x);
  const xs = Array.from({length: N}, (_, n) => x0 + n * dx), ys = xs.map(sig);
  const M = Math.floor(N / 2), re = new Float64Array(M + 1), im = new Float64Array(M + 1);
  for (let m = 0; m <= M; m++) for (let n = 0; n < N; n++) { const a = -2 * Math.PI * m * n / N; re[m] += ys[n] * Math.cos(a); im[m] += ys[n] * Math.sin(a); }
  const amp = Array.from({length: M + 1}, (_, m) => ({m, f: m / T, A: (m === 0 ? 1 : 2) * Math.hypot(re[m], im[m]) / N, ph: Math.atan2(im[m], re[m])}));
  const kept = amp.slice(1).sort((a, b) => b.A - a.A).slice(0, ftK);
  const rec = x => amp[0].A * Math.cos(amp[0].ph) + kept.reduce((s, c) => s + c.A * Math.cos(2 * Math.PI * c.f * (x - x0) + c.ph), 0);
  const fine = Array.from({length: 600}, (_, i) => x0 + T * i / 599);
  const fNy = 1 / (2 * dx);
  const alias = f => { const fs = 2 * fNy; let g = Math.abs(f - Math.round(f / fs) * fs); return g; };
  return {T, dx, N, x0, xs, ys, fine, sig, rec, amp, kept, fNy, alias};
}

What you see. Top: the true continuous signal in grey, its samples as blue dots, and in orange the signal rebuilt from the \(K\) strongest DFT components. Bottom: the amplitude spectrum, one stem per DFT frequency \(f_m = m/T\), up to the Nyquist frequency marked by the red dashed line. Stems used in the reconstruction are orange, the rest blue. The green dashed lines mark where the two true frequencies \(f_1\) and \(f_2\) land in the spectrum; when a frequency lies above Nyquist, its green line sits at the aliased frequency instead.

Try: set \(f_2\) above the Nyquist frequency and watch its energy appear at the wrong place. Make \(T\) a non-integer multiple of the period and the peak smears over neighbouring frequencies (leakage). With \(K = 2\) and well-resolved peaks, the orange reconstruction sits exactly on the grey signal. From the Fourier exercises in Theoretical Neuroscience.
