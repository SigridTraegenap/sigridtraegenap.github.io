Recurrent networks: from kernel to pattern

A difference-of-Gaussians kernel, its spectrum, and a ring network that turns noise into stripes.

How local excitation and lateral inhibition pick out a spatial frequency, and what a network built from such a kernel does with random input. Everything on this page runs in your browser; nothing to install. Change a slider while a simulation is running and it reacts immediately.

Difference of Gaussians and its spectrum

A local-excitation, lateral-inhibition kernel is the difference of two Gaussians. Its Fourier transform tells you which spatial frequency a recurrent network with this kernel will amplify most; the next explorable shows that network in action.

Code 
viewof sigE = Inputs.range([0.1, 10], {value: 1, step: 0.1, label: "Excitation width σₑ"})
viewof ampE = Inputs.range([0, 10], {value: 1, step: 0.1, label: "Excitation strength"})
viewof sigI = Inputs.range([0.1, 10], {value: 2, step: 0.1, label: "Inhibition width σᵢ"})
viewof ampI = Inputs.range([0, 2], {value: 1, step: 0.05, label: "Inhibition strength"})

gauss = (x, s) => Math.exp(-0.5 * x * x / (s * s)) / (Math.sqrt(2 * Math.PI) * s)
ghat = (f, s) => Math.exp(-2 * Math.PI * Math.PI * s * s * f * f)
xmax = 5 * Math.max(sigE, sigI)
space = Array.from({length: 401}, (_, i) => {
  const x = -xmax + 2 * xmax * i / 400;
  const e = ampE * gauss(x, sigE), inh = -ampI * gauss(x, sigI);
  return {x, Excitation: e, Inhibition: inh, "Difference of Gaussians": e + inh};
})
spectrum = Array.from({length: 401}, (_, i) => { const f = 2 * i / 400; return {f, k: Math.abs(ampE * ghat(f, sigE) - ampI * ghat(f, sigI))}; })
peak = spectrum.reduce((a, b) => (b.k > a.k ? b : a))

Right: the magnitude of the kernel’s Fourier transform in grey; the orange dashed line marks the spatial frequency with the largest value, the one a recurrent network with this kernel amplifies most.

Pattern formation in a recurrent network

A ring of neurons, each exciting its close neighbours and inhibiting those a bit further away. Such a kernel amplifies one spatial frequency more than any other, so even random input turns into a regular pattern.

\[\tau \frac{dr}{dt} = -r + \left[\,W r + h\,\right]_+\]

  • \(r\): the firing rates of the 256 neurons on the ring.
  • \(W\): the connection matrix. Neuron \(i\) receives from neuron \(j\) a weight that depends only on their distance: a narrow positive Gaussian (excitation) minus a wider negative one (inhibition). The two width sliders set those Gaussians.
  • \(h\): a fixed random external input, one value per neuron, plus optional noise that is redrawn at every time step (the noise slider).
  • \([\cdot]_+\): rectification, negative values are set to zero.
  • \(\tau\): the time constant; the clock in the figure counts in units of \(\tau\).
  • Gain: \(W\) is scaled so that its largest eigenvalue equals the gain slider. Above 1 the corresponding pattern grows; below 1 it decays.
Code 
viewof rnSigE = Inputs.range([1, 25], {value: 5, step: 0.5, label: "Excitation width"})
viewof rnSigI = Inputs.range([1, 50], {value: 12, step: 0.5, label: "Inhibition width"})
viewof rnGain = Inputs.range([0.2, 1.6], {value: 1.2, step: 0.02, label: "Gain (largest eigenvalue of W)"})
viewof rnNoise = Inputs.range([0, 1], {value: 0.1, step: 0.02, label: "Input noise"})
viewof rnPause = Inputs.toggle({label: "Pause"})
viewof rnReset = Inputs.button("Reset")
Code 
rnN = 256
rnKernel = {
  const N = rnN, sE = rnSigE, sI = rnSigI;
  const g = (d, s) => Math.exp(-0.5 * d * d / (s * s)) / s;
  const k = new Float64Array(N);
  for (let d = 0; d < N; d++) { const dd = Math.min(d, N - d); k[d] = g(dd, sE) - g(dd, sI); }
  const ev = new Float64Array(N / 2 + 1);
  for (let m = 0; m <= N / 2; m++) { let s = 0; for (let d = 0; d < N; d++) s += k[d] * Math.cos(2 * Math.PI * m * d / N); ev[m] = s; }
  let lmax = -Infinity, mmax = 0; for (let m = 0; m <= N / 2; m++) if (ev[m] > lmax) { lmax = ev[m]; mmax = m; }
  const scale = rnGain / lmax;
  return {N, k: k.map(x => x * scale), ev: ev.map(x => x * scale), mmax};
}
rnState = {
  rnReset;
  const N = rnN, dt = 0.1, tau = 1;
  const h = Float64Array.from({length: N}, () => 0.5 + 0.5 * Math.random());
  let r = new Float64Array(N).fill(0.5), t = 0;
  while (true) {
    if (!viewof rnPause.value) {
      const {k} = rnKernel; const noise = viewof rnNoise.value;
      for (let step = 0; step < 5; step++) {
        const rn = new Float64Array(N);
        for (let i = 0; i < N; i++) {
          let s = 0;
          for (let j = 0; j < N; j++) { const d = (i - j + N) % N; s += k[d] * r[j]; }
          rn[i] = r[i] + dt / tau * (-r[i] + Math.max(0, s + h[i] + noise * (Math.random() - 0.5) * 2));
        }
        r = rn; t += dt;
      }
    }
    yield {r, t};
  }
}

What you see. Top: the activity \(r\) of each neuron as a blue bar, by position on the ring. Bottom: the eigenvalues of \(W\) for each spatial frequency, counted in waves around the ring, as grey dots. The orange dot is the largest eigenvalue, the frequency the network amplifies most. The red dashed line marks eigenvalue 1, the boundary between decay and growth.

Try: with the gain below 1 the pattern fades and only the random input remains. Above 1, the frequency marked in orange takes over. Make the inhibition wider and the stripes get broader. From the pattern-formation exercise in Theoretical Neuroscience.
